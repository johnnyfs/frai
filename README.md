# frai

Minimal NetHack-style TTY roguelike built with Python 3.12+ and stdlib curses.

Run with:

```sh
uv run python -m src.main
```

Rules content note: character-creation option names are a small, data-driven
starter set derived from D&D SRD-style 5e material. The official SRD v5.2.1 is
published by Wizards of the Coast under CC-BY-4.0:
https://www.dndbeyond.com/srd
